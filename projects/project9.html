Nashville Housing Data Cleaning

Transformed 56,478+ rows of messy, real-world real estate data into a clean, structured, and analysis-ready format using advanced SQL techniques including Self-Joins, CTEs, Window Functions, and String Manipulation.

The Challenge

Real-world datasets are rarely clean. This Nashville Housing dataset contained over 56,000 records with inconsistent datetime formats, NULL property addresses, merged address strings, ambiguous categorical values ('Y'/'N'), and duplicate entries. The goal was to systematically resolve these issues using pure SQL.

SQL Techniques Used

  • Self-Joins: To intelligently populate missing values using related records.
  • CTEs & Window Functions: ROW_NUMBER() for precise and safe duplicate removal.
  • String Functions: SUBSTRING, CHARINDEX, and PARSENAME for data splitting.
  • Conditional Logic: CASE statements for standardizing categorical data.

Step-by-Step Cleaning Process

1 Standardize Date Format

Converted the messy datetime SaleDate into a standard DATE format and created a dedicated column for consistency.

ALTER TABLE NashvilleHousing ADD SaleDateConverted DATE; UPDATE NashvilleHousing SET SaleDateConverted = CONVERT(DATE, SaleDate);

2 Populate Missing Property Addresses

Identified NULL PropertyAddress values and used a Self-Join on ParcelID to fill them using data from other records with the same Parcel ID.

UPDATE a SET PropertyAddress = ISNULL(a.PropertyAddress, b.PropertyAddress) FROM NashvilleHousing a JOIN NashvilleHousing b ON a.ParcelID = b.ParcelID AND a.[UniqueID ] <> b.[UniqueID ] WHERE a.PropertyAddress IS NULL;

3 Split Address Into Individual Columns

Separated the merged PropertyAddress and OwnerAddress into distinct columns (Address, City, State) using string manipulation functions.

-- Split Property Address ALTER TABLE NashvilleHousing ADD PropertySplitAddress NVARCHAR(255); UPDATE NashvilleHousing SET PropertySplitAddress = SUBSTRING(PropertyAddress, 1, CHARINDEX(',', PropertyAddress) - 1); -- Split Owner Address using PARSENAME ALTER TABLE NashvilleHousing ADD OwnerSplitState NVARCHAR(255); UPDATE NashvilleHousing SET OwnerSplitState = PARSENAME(REPLACE(OwnerAddress, ',', '.'), 1);

4 Standardize Categorical Values

Changed inconsistent 'Y' and 'N' values in the SoldAsVacant field to 'Yes' and 'No' for better readability and analysis.

UPDATE NashvilleHousing SET SoldAsVacant = CASE WHEN SoldAsVacant = 'Y' THEN 'Yes' WHEN SoldAsVacant = 'N' THEN 'No' ELSE SoldAsVacant END;

5 Remove Duplicate Records

Used a Common Table Expression (CTE) with the ROW_NUMBER() window function to identify and safely delete exact duplicate rows.

WITH RowNumCTE AS ( SELECT *, ROW_NUMBER() OVER ( PARTITION BY ParcelID, PropertyAddress, SalePrice, SaleDate, LegalReference ORDER BY UniqueID ) AS row_num FROM NashvilleHousing ) DELETE FROM RowNumCTE WHERE row_num > 1;

6 Drop Unused Columns

Removed the original, now-redundant columns to optimize the final table structure.

ALTER TABLE NashvilleHousing DROP COLUMN OwnerAddress, TaxDistrict, PropertyAddress, SaleDate;
