A **professional, responsive, and comprehensive** data analytics portfolio showcasing 9+ end-to-end projects across **Power BI, SQL, Python, Excel, and Tableau**. This repository demonstrates my expertise in transforming messy, real-world data into clean, structured, and visually compelling business insights that drive decision-making.

- **$4.25M+ revenue** analyzed across multiple business domains (Retail, FMCG, Real Estate)
- **2+ years** of hands-on industry experience in MIS reporting and dashboard development
- **100% responsive** web design optimized for all devices
